# شذرات

**تدوينات مصغرة لموقعك الشخصي عن طريق ماستدون.**

شذرات عبارة عن ملفي HTML بسيطين لعرض منشورات حساب ماستدون في موقعك الشخصي، دون الحاجة إلى مكتبات أو إعدادات معقدة.

يمكنك أخذ الملف الذي يناسبك وتخصيص مظهره بما يناسب موقعك.

اعتبره تويتر شخصي ولكن في موقعك
## مثال

يمكنك مشاهدة تطبيق الفكرة على موقعي الشخصي:

**[fatimamalam](https://fatimamalam/statuslog.xyz/)**
## من اين أتت الفكرة؟
اعجبت بالفكرة عندما شاهدتها في المواقع المذكورة ادناه. وعندما كنت اقوم بصنع موقعي. تسألت كيف يمكنني فعل شيء بسيط مماثل. وماستدون كان حلي.  


المواقع:

* [Status.lol](https://status.lol/) — منصة للتدوين المصغر والحالات القصيرة.
* [Status.cafe](https://status.cafe/) — منصة لمشاركة الحالات القصيرة.
* [Bear Blog — Short-form content](https://sylvia.bearblog.dev/short-form-content/) — مثال على عرض المحتوى القصير ضمن مدونة شخصية.
* [شذرات — فؤاد الفرحان](https://alfarhan.ws/micro/) — مثال عربي جميل على استخدام التدوين المصغر داخل موقع شخصي.

## المتطلبات

لا يحتاج شذرات إلى مكتبات أو برامج إضافية.

كل ما تحتاجه هو موقع يستطيع تشغيل HTML وJavaScript.
## النسخ

### التمرير اللانهائي

افتح ملف:

`mastodon-infinite-scroll.html`

تظهر المنشورات تباعًا، ويتم تحميل المنشورات الأقدم تلقائيًا عند الوصول إلى نهاية القائمة.

### الصفحات

افتح ملف:

`mastodon-pagination.html`

تعرض المنشورات على دفعات، ويمكنك التنقل بينها باستخدام زري **الأحدث** و**الأقدم**.
## الاستخدام

افتح الملف الذي تريد استخدامه، وابحث عن:

```javascript
const account = "https://mastodon.social/@username";
```

استبدله برابط حسابك على ماستدون: 

```javascript
const account = "https://الخادم.com/@اسم_المستخدم";
```

ثم انسخ الكود إلى موقعك.

هذا كل شيء. 
## التخصيص

يمكنك تخصيص مظهر المنشورات مباشرة من قسم CSS الموجود داخل ملف HTML.

وفي نسخة الصفحات يمكنك أيضًا تغيير عدد المنشورات في كل دفعة:

```javascript
const postsPerPage = 20;
```

## الوسائط

يعرض شذرات الوسائط الموجودة في منشورات ماستدون بما في ذلك:

* الصور
* GIF
* الفيديو
* الصوت
* معاينات الروابط
